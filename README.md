## 给AI写的提示题
请把以下 Python 可读性要求写入当前项目的 AGENTS.md。
如果已有 Python 编程规范，在原章节中补充并协调重复内容；
如果没有 AGENTS.md，在项目根目录创建。保留其他已有要求。

核心原则：代码应便于人逐行理解、调试和修改，不追求行数少。

具体要求：
1. 多步骤处理默认使用普通 for 循环。
2. 列表、字典、集合推导式仅用于简单、单层、容易直接理解的操作，
   例如提取一个字段或进行一次简单转换。
3. 包含多个筛选条件、嵌套循环、复杂条件表达式、
   数据修改或统计时，优先使用普通循环，分步骤表达。
4. 避免嵌套推导式，以及在推导式中调用会修改数据的操作。
5. if、elif、else、for、while 后的执行语句换行并缩进，
   不把判断与执行操作挤在同一行。
6. 较长条件使用括号换行，每行表达一个清楚的条件。
7. 确实需要逐个读取大量数据、节省内存时，可以使用生成器；
   保留其按需产生数据的特点，不直接改成一次性构建完整列表。
8. 不为缩短代码而使用晦涩写法，也不为拆行而引入不必要的抽象。
9. 遵循项目已有格式约定；没有约定时参考 PEP 8。

本次修改范围为项目开发规范。后续新增或修改 Python 代码时，
按照上述要求执行，避免顺带修改无关代码。
